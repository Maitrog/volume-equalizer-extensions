Patch Notes 2.4.0

  • Reworked tab capture
    • Removed the window mode, tab capture is now managed directly from the popup but you still need to click on the button
    • Audio is now processed in the offscreen, so capture keeps working after closing the popup
You may think that the new capture mode more convenient than the default one, but the new capture mode can't handle auto start rules. That's why the new mode can't be used as default.
  • Spectrum visualization is now enabled by default
  • Automatic volume compensation is now disabled by default
  • Improved recovery of the page equalizer after capture interruptions (e.g. service worker or offscreen restarts)
  • Fixed the capture error message remaining after a successful start
  • Fixed spectrum not switching when changing the selected captured tab
  • Fixed incorrect equalizer state shown in the popup during capture
  • Fixed issues when starting capture repeatedly
  • Updated localization

  • Improved language switching when multiple selections happen quickly

  • Improved keyboard navigation throughout the popup

  • Improved usability at 100% and 200% browser zoom
  • Different things were made to improve performance
  • Updated localization

Patch Notes 2.0.0

  • Redesigned popup interface
    • Controls are now grouped into clear sections.
    • Added a compact equalizer enable/disable button with a visible active state.
    • The current gain value is displayed in dB.
    • Updated controls, checkboxes, settings, and modal styles.
  • Built-in audio presets
    • Added 13 presets, including Bass Boost, Acoustic, Classical, Rock, and Pop.
    • Added an option to hide built-in presets.
  • Improved custom presets
    • Custom presets are now created in a dedicated modal.
    • Added validation for empty, duplicate, and reserved preset names.
  • Improved window mode
    • Added spectrum visualization for the active tab.
    • Added switching between captured tabs.
    • Added the ability to stop audio capture for an individual tab.
  • Real-time spectrum visualization
    • The spectrum now responds to filter and settings changes in real time.
  • New onboarding guide
    • Introduces themes, shortcuts, equalizer controls, volume, and presets.
    • Highlights relevant interface elements.
    • Supports Back, Next, Skip, and Finish actions.
    • Resumes automatically if onboarding was not completed.
  • Added Lao localization. Thanks bounkirdni-2025
  • Updated localization files.
  • Added translator credits to the Community section.
  • Added an uninstall feedback form.
